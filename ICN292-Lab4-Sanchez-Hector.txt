\section*{Entregable 1: Creación de la Base de Datos y Modelo Entidad--Relación}

\subsection*{1.1 Reconstrucción de la Base de Datos \texttt{austral}}
De acuerdo con el escenario planteado para **Austral Editores**, se construyó el script SQL completo que inicializa la base de datos desde un estado limpio e incorpora tanto las tablas base del catálogo inicial (\texttt{autores} y \texttt{libros}) como las tablas adicionales requeridas (\texttt{colecciones} y \texttt{pagos}).

\begin{lstlisting}
DROP DATABASE IF EXISTS austral;
CREATE DATABASE austral;
USE austral;

-- Tabla 1: autores
CREATE TABLE autores (
    id_autor INT AUTO_INCREMENT,
    nombre VARCHAR(80) NOT NULL,
    pais VARCHAR(60),
    genero ENUM('Cómic', 'Ensayo', 'Infantil', 'Novela', 'Poesía') NOT NULL,
    PRIMARY KEY (id_autor)
);

-- Tabla 2: colecciones
CREATE TABLE colecciones (
    id_coleccion INT AUTO_INCREMENT,
    titulo VARCHAR(120) NOT NULL,
    fecha_publicacion DATE NOT NULL,
    PRIMARY KEY (id_coleccion)
);

-- Tabla 3: libros
CREATE TABLE libros (
    id_libro INT AUTO_INCREMENT,
    id_autor INT,
    id_coleccion INT,
    titulo VARCHAR(120) NOT NULL,
    paginas INT,
    ejemplares_vendidos INT,
    anio INT,
    PRIMARY KEY (id_libro),
    FOREIGN KEY (id_autor) REFERENCES autores(id_autor),
    FOREIGN KEY (id_coleccion) REFERENCES colecciones(id_coleccion)
);

-- Tabla 4: pagos
CREATE TABLE pagos (
    id_pago INT AUTO_INCREMENT,
    id_autor INT,
    fecha_pago DATE NOT NULL,
    monto DECIMAL(10,2) NOT NULL,
    PRIMARY KEY (id_pago),
    FOREIGN KEY (id_autor) REFERENCES autores(id_autor)
);
\end{lstlisting}

\subsection*{Consulta 1}
\textbf{Requerimiento:} Muestre el nombre y el género de los autores cuyo país no es Chile, incluyendo a quien no tiene país registrado, ordenados por nombre. En el informe explique, en una línea, qué devuelve la comparación \texttt{pais <> 'Chile'} y por qué.

\begin{lstlisting}
SELECT nombre, genero 
FROM autores 
WHERE pais <> 'Chile' OR pais IS NULL 
ORDER BY nombre ASC;
\end{lstlisting}

\textbf{Explicación requerida:} La comparación \texttt{pais <> 'Chile'} descarta por defecto los valores \texttt{NULL} (como el de Kenji Arakawa) porque en SQL ningún valor vacío se evalúa como verdadero ni falso frente a operadores relacionales, haciendo obligatorio incluir explícitamente \texttt{OR pais IS NULL}.

\subsection*{Consulta 5}
\textbf{Requerimiento:} Muestre el nombre de cada autor que tiene más de un libro publicado en 2024 y cuántos son. Ordene por nombre.

\begin{lstlisting}
SELECT 
    a.nombre, 
    COUNT(*) AS libros_2024 
FROM autores a 
JOIN libros l ON a.id_autor = l.id_autor 
WHERE l.anio = 2024 
GROUP BY a.id_autor, a.nombre 
HAVING COUNT(*) > 1 
ORDER BY a.nombre ASC;
\end{lstlisting}

\subsection*{Consulta 10}
\textbf{Requerimiento:} Liste los pagos hechos a los autores con fecha y monto, y luego muestre el total pagado a cada autor.

\begin{lstlisting}
-- Sentencia 1: Detalle de pagos
SELECT 
    a.nombre, 
    p.fecha_pago, 
    p.monto 
FROM pagos p 
JOIN autores a ON p.id_autor = a.id_autor;

-- Sentencia 2: Total pagado por autor
SELECT 
    a.nombre, 
    SUM(p.monto) AS total_pagado 
FROM pagos p 
JOIN autores a ON p.id_autor = a.id_autor 
GROUP BY a.id_autor, a.nombre;
\end{lstlisting}
